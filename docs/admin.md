# 관리자 (Admin)

> 관리자는 가맹점 무관 (`gym_id` = NULL). 전체 가맹점·구독·invite를 관리.

## 관리자 계정

- 환경변수 `ADMIN_EMAIL` + `ADMIN_INITIAL_PASSWORD`
- seed 스크립트가 첫 관리자 등록 (`gym_id` NULL, role=admin)
- 첫 로그인 시 비번 변경 권장
- 추가 관리자 V2 (V1은 1인 운영)
- 로그인 URL: `/admin/login`

## 가맹점 invite link 발급 (M5 핵심)

신규 가맹점은 공개 가입 없이 invite link로만 가입 가능. 관리자가 발급·전달.

### 발급 흐름
1. 오프라인으로 사장 컨택 → 관리자가 admin 패널에서 "신규 invite 발급" 클릭
2. 메모 입력 (관리자 본인용):
   - 예상 매장명
   - 사장 연락처·이름
3. 시스템이 invite token 생성 → URL 출력 (`yeyak.com/register?token=...`)
4. 관리자가 URL 복사해서 사장에게 메일·메신저 등으로 전달
5. 사장이 7일 안에 클릭 → 매장 등록 폼 → 가입 완료 시 token 무효화

### Invite 관리
- invite 리스트: pending(미사용·유효) / used(가입 완료) / revoked(회수)
- 미사용 invite "회수" 버튼 (오발급·연락 두절 시)
- 만료 7일 자동
- 통계: 발급 수, 가입 전환 수, 평균 응답 시간

### Invite 보존 정책
- **expired** (만료·미사용) → admin 페이지 진입 시 자동 삭제 (lazy cleanup, cron 불필요). 화면에는 노출 X
- **used** (사용 완료) → 영구 보존. 가맹점 가입 audit (어떤 invite로 가입했는지). 가맹점 1:1이라 row 부담 미미
- **revoked** (관리자 회수) → 영구 보존. 회수 의도 자체가 audit 가치
- **pending** (미사용·유효) → 만료 전까지 보존, 만료 시 expired로 전환되며 곧 자동 삭제

## 가맹점 관리

### 가맹점 리스트
- 필터: 전체 / 무료 체험중 / 구독중 / 유예중 / 미구독·만료 / 차단
- 컬럼: 매장명·슬러그·사장 이메일·전화·가입일·구독 만료일·매출

### 가맹점 차단·재활성화
- 위반 시 관리자가 수동 차단
- 차단 시: 검색·예약·QR 출입 모두 막힘 (`Business.status = blocked`)
- 차단 사유 메모 필드
- 재활성화 1클릭

### 가맹점 정보 수정 (긴급)
- 사장 이메일 오타 등 가입 후 수정 필요 시 관리자가 직접 수정
- 슬러그 변경: V2 (URL 변경은 PWA 설치·QR에 영향 → 신중)

### 사장 비밀번호 재설정 메일 발송 (헬프데스크)
- 가맹점 상세 화면의 "차단" 버튼 오른쪽에 "비밀번호 재설정 메일" 버튼
- 사장이 loginId 자체를 잊은 경우 self-service "비번 찾기" 흐름이 막혀, admin 트리거로 구제
- 동작: 활성 OWNER 1명 찾아 1회용 reset 링크 메일 발송 (`magicLinkToken` purpose=PASSWORD_RESET, 7일 만료, 발급 시 기존 미사용 토큰 일괄 무효화)
- 평문 임시 비번을 메일에 넣지 않음 (메일 인박스 평문 잔류 / 가로채기 방지). 사장이 링크 클릭해 본인이 새 비번 직접 입력
- 10 분 쿨다운 (직전 발송 토큰 createdAt 기준)
- 확인 모달에 매장명·사장 이름·받는 메일 명시
- 호텔 매장도 같은 버튼. URL 패턴은 호텔 측 합의안 `{HOTEL_PUBLIC_BASE_URL}/{lang}/h/{slug}/reset-credentials?token=...` 사용, 헬스장 admin 이 호텔 DB 의 `magicLinkToken` 에 직접 insert
- 이메일 미등록 사장은 버튼 비활성 (가맹점 등록 form 이 email 필수라 실제로는 발생 안 함)

## 구독 관리

### 자동 trial
- 신규 가맹점 가입 즉시 3개월 무료 체험 자동 시작
- 별도 "승인" 절차 없음 (invite 발급이 사실상 승인)

### 결제 확인
- 사장이 현금 또는 송금 → 관리자가 "입금 확인 완료" 수동 클릭
- 결제 후 구독 기간 갱신 (예: 3개월 더)
- 입금 메모 필드 (송금 일자·방법)

### 만료 처리
- 만료일 다음날부터 7일 유예 (정상 운영 유지)
- 7일 후 미확인 시 자동 비활성화 (검색·예약·QR 출입 모두 차단)
- 비활성화 후 사장이 입금하면 관리자가 재활성화

### 환불
- 매장이 환불 요청 → 관리자 승인
- 환불 금액: 남은 기간의 50%
- 환불은 매장 직접 입금 (현금 운영, 시스템은 기록만)

## 통계

### 플랫폼 전체
- 매출 현황 (일별·월별)
- 가맹점 수 (활성·체험·만료·차단)
- 가맹점별 활성 회원 수·신규 회원 수

### 가맹점별 드릴다운
- 매장 단위 매출·예약 수·노쇼율
- 헬스장 출입 통계 (자유 운동·PT·단체 구분)

### 데이터 다운로드
- Excel 또는 CSV
- 사장에게도 매장 단위 다운로드 제공 (사장 대시보드 측)

## 회원 관리 (전체 가맹점 횡단)

- 가맹점·이메일·이름으로 검색
- 신뢰도 점수별 조회 (블랙 등급 리스트)
- 탈퇴 신청 회원 리스트 (1달 유예 중)
- **회원 정보 수정·삭제는 가맹점 사장의 권한**. 관리자는 조회만 (V1)
- V2: 어뷰징 회원 글로벌 정지 (정책 미정)

## 위치 마스터 관리

- City + Barangay 마스터 데이터 (PSGC)
- 시드: NCR 17개 시 + 모든 Barangay
- 관리자가 추가 도시 (세부·다바오 등) 확장

## 시스템

- DB 백업 상태 모니터링 (하루 1회 자동, 30일 보관)
- 알림 발송 로그 조회 (V2)
- 에러 로그 (V2 — Sentry 도입 후)
