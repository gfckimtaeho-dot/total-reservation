# 고객 관리 (Customer)

> 모든 고객 관련 데이터(`User`·`Membership`·`Package`·`TrustScore`·`Reservation`)는 `gym_id` 스코프. 같은 사람이 가맹점 A·B 회원이면 신뢰도·멤버십·패키지 모두 별개.

## 신뢰도 점수

| 이벤트 | 변동 |
|---|---|
| 신규 가입 | 100점 시작 |
| 정상 방문 완료 | +5 |
| 노쇼 | -30 |
| 직원·사장이 변경한 예약 | 패널티 X |
| 고객이 하루 전까지 변경·취소 | 패널티 X |

## 등급

| 등급 | 점수 |
|---|---|
| 일반 | 90점 이상 |
| 주의 | 70 ~ 89점 |
| 블랙 | 69점 이하 |

## 노출 정책

- **사장·직원 화면**: 고객 리스트에 점수 + 등급 표시
- **고객 본인 마이페이지**: 점수 + 등급 노출 (자기 행동 결과 인식 효과)

## 블랙 회원 처리

- 시스템: 사장 화면에 **경고 표시만** (예약 신청 시 빨간 배너)
- 차단: 사장이 **수동으로 예약 거부**
- 자동 차단 X (사장 재량)
- 이의제기 시스템 없음 (사장 신뢰)

## 노쇼 처리

- 1:1 서비스 (PT 등): 시간 지난 후 사장·트레이너가 "노쇼" 버튼 클릭
- 단체 수업: 출석 토글 UI에서 회원별 "노쇼" 체크
- 모두 자동 -30 적용

## 멤버십·패키지

### 멤버십 (출입권)
- 사장이 회원 편집 화면에서 등록 (시작일·종료일·금액)
- 만료일 도달 시 QR 자동 발급 차단
- 만료 7일 전 알림 (옵션)

### PT 패키지 (회당 시술권)
- 사장이 회원 편집 화면에서 등록 (예: PT 10회권, 잔여 횟수 카운터)
- **예약 확정 시 자동 차감** (-1)
- 잔여 0회 시 새 패키지 결제 안내
- 결제는 매장 직접 (시스템은 횟수만 추적)

### 결제 원칙
- 멤버십·패키지 모두 매장이 현금·GCash·카드 등으로 직접 수금
- 시스템은 기록만 (금액·시작일·종료일·잔여 횟수)
- 영수증 발급은 매장 자율

## 회원 등록 권한

- 사장·매니저·트레이너 모두 가능
- 매장 태블릿에서 신규 손님 즉석 등록 (사장 부재 시 트레이너 대응)
- 등록·결제 모두 트레이너 가능
- 가입 흐름은 [auth.md](./auth.md)의 "고객 (트레이너가 태블릿에서 등록)" 참조

## 고객 마이페이지

- 내 예약 목록 (월별 캘린더)
- 예약 상태: 입금 대기 / 확정 / 완료 / 취소 / 거절
- 당일 예약 확인 (홈에 강조)
- 본인 정보 수정 (이름·전화번호)
- 본인 신뢰도 점수·등급
- 출입 QR (멤버십 활성 시)
- 알림 설정:
  - 푸시 ON / OFF
  - 이메일 ON / OFF
  - (둘 다 OFF 시 어떤 알림도 못 받음)

## 비회원 정책

- **모든 예약·QR 출입은 회원 전용**
- 비회원이 매장 방문 시 트레이너가 태블릿에서 신규 등록 → 고객 이메일로 magic link 자동 발송 → 고객이 본인 폰에서 PWA 설치 + 비번 설정 → 활성화
- 가입은 100% 매장 방문 경로 (공개 가입 페이지 없음)
