## 2. 비즈니스 모델 — 가맹점형 SaaS

- **단일 vertical**: 헬스장 전용. 마사지샵·호텔·식당 등은 V2가 아니라 **별도 프로젝트**로 분리 (이 명세를 복제 후 vertical 특화 부분만 수정).
- **가맹점 모델**: 헬스장 N개가 가입해도 같은 코드·같은 화면을 받음. 각 헬스장에 고유 슬러그(=`gym_id`) 부여. 운영 주체·고객·매출은 가맹점별 완전 분리.
- **영업 채널**: 오프라인 (관리자가 사장 직접 컨택). 공개 가입 페이지 없음.
- **가입 흐름**: 관리자(나)가 admin 패널에서 invite link(1회용 토큰 URL) 발급 → 사장에게 메일·메신저로 전달 → 사장이 링크로 매장 등록 폼 채움 → 가입 완료.
- **고객 계정 범위**: 가맹점별 분리. A체육관 회원이 B체육관도 이용하려면 B에 별도 가입.

### 구독료 (사장 ↔ 관리자)
- 1개월 2500₱ / 3개월 6000₱ / 6개월 9000₱ / 1년 16000₱
- 신규 매장: 3개월 무료 체험 자동 시작 (가입 즉시)
- 만료 다음날부터 7일 유예 → 이후 자동 비활성화 (예약·QR 출입 모두 차단)
- 결제: 현금 수금 (관리자 수동 확인). GCash 자동화는 V2.
- 환불: 매장 환불 요청 시 관리자 승인, 남은 기간 50%
- 고객은 무료, 광고 없음

## 3. URL 구조 (멀티테넌트)

| URL | 역할 |
|---|---|
| `yeyak.com/` | 안내 페이지 (관리자 로그인 링크만 노출, 일반 사용자는 갈 곳 없음) |
| `yeyak.com/admin` / `yeyak.com/admin/login` | 관리자 패널 (전체 가맹점·구독·invite 발급) |
| `yeyak.com/register?token={invite}` | 사장 매장 등록 폼 (invite 토큰 검증 후 진입) |
| `yeyak.com/g/{slug}/` | **매장 공개 페이지** — 매장이 자체 홈페이지 역할로 사용. 사진 갤러리·소개·영업시간·서비스·트레이너·멤버십·연락처. 비회원도 진입 가능. 가입 자체는 매장 방문 100% (페이지에 공개 가입 폼 X). 회원 진입 시 PWA 설치 가이드 + 로그인 링크 노출. 자세한 표시 항목은 [business.md](./business.md) |
| `yeyak.com/login` | **통합 로그인** — 이메일+비번 한 번에. 같은 이메일이 여러 매장에 있어도 비번 일치한 매장 중 가장 최근 가입한 매장으로 자동 진입. role별 redirect (OWNER/MANAGER/TRAINER → dashboard, CUSTOMER → me). 사장·트레이너·고객 모두 같은 진입점. 매장 slug 몰라도 됨 |
| `yeyak.com/g/{slug}/login` | 매장 직접 로그인 (환영 메일·북마크에서 직접 들어올 때). 이메일+비번. `/login`이 default고 이건 매장 선택 우회용 (다중 매장 동일 비번 같은 rare case에 유용) |
| `yeyak.com/g/{slug}/forgot` | 가맹점 비번 재설정 (magic link 발송) |
| `yeyak.com/g/{slug}/activate?token={magic}` | 신규 사용자 활성화 + 비번 설정 |
| `yeyak.com/g/{slug}/dashboard` | 사장·트레이너 운영 화면 (auth + role 검사) |
| `yeyak.com/g/{slug}/me` | 고객 마이페이지·QR (auth) |

> 슬러그(`{slug}`) = 사장이 매장 등록 시 직접 입력. 영문/숫자/하이픈만, 시스템 예약어(`admin`, `g`, `api`, `register`, `login`, `forgot`, `activate` 등) 금지. 가입 폼에서 실시간 중복·예약어 체크.

## 4. 사용자 유형

- **관리자 (Admin)**: 운영자 본인. 환경변수 `ADMIN_EMAIL`로 식별. `gym_id` 없음. 모든 가맹점·구독·invite 관리.
- **사장 (Owner)**: 가맹점 1개 운영. 매장 삭제 가능.
- **매니저 (Manager)**: 사장과 동등 권한, 매장 삭제만 불가.
- **트레이너 (Staff)**: 본인 예약 + 회원 등록·결제.
- **고객 (Customer)**: 가맹점별 가입. 예약·QR 출입.

## 5. 기기 모델 (운영 현실)

| 기기 | 사용자 | 용도 |
|---|---|---|
| 32" 모니터 (웹) | 사장 | 예약·단체 수업·매출 오버뷰 (사령탑) |
| 태블릿 | 사장 또는 트레이너 (1인 1태블릿) | 예약 등록·신규 회원 등록·결제 입력·출석 체크 |
| 개인 폰 | 고객 | PWA 설치 후 QR 출입 + 예약 조회·신뢰도 확인 |

> 1 코드베이스, 반응형 PWA. 기기별 별도 앱 없음. 32"는 wide 레이아웃, 태블릿은 medium, 폰은 mobile.
> 태블릿은 직원 개인 소유 → 자동 로그아웃·PIN 없음. 로그인된 user_id가 모든 액션의 actor.

## 7. 인증 핵심 — OTP 제거 / Magic link 통일

- **OTP 6자리 코드 메커니즘 사용 안 함**. 모든 이메일 소유 증명은 일회용 URL 클릭(magic link)로 통일.
- 적용 흐름: 신규 회원 활성화 / 트레이너 초대 / 비번 재설정.
- 사장 매장 등록은 invite link(관리자 발급) 자체가 신원 검증을 대신하므로 별도 magic link 없이 즉시 활성화.
- Magic link 만료: 24시간 일괄.

## 11. 데이터·보안 정책

- **가맹점 격리**: 모든 도메인 row에 `gym_id` FK. Server Action·API route 진입점에서 `gym_id`(URL slug에서 도출) 검증 후 모든 쿼리에 강제 주입. 다른 매장 데이터 노출 0건이 목표.
- 회원 탈퇴: 신청 후 1달 유예 ("탈퇴 취소"만 가능, 유예 중 같은 가맹점 재가입 불가). 1달 후 익명화 (이름="탈퇴회원", 이메일·전화 삭제).
- **재가입 시 신뢰도 100점부터** 새로 시작 (같은 가맹점에서). 다른 가맹점은 항상 별도 계정이라 무관.
- 예약 기록: 영구 보관 (탈퇴 회원은 "탈퇴회원"으로 표시).
- DB 백업: 하루 1회 자동, 30일 보관.
- 필리핀 Data Privacy Act 준수.
- 약관·개인정보처리방침은 출시 전 작성.

## 12. PWA 정책

- "홈 화면에 추가" 안내로 설치
- 모든 사용자 화면 (고객·사장·트레이너·관리자) PWA
- 신규 회원 가입 시 매장에서 PWA 설치 안내 메일 자동 발송 (= magic link 메일에 설치 안내 포함)
- **오프라인 시 출입 검증 안 함, 그냥 입장 허용** (V1 단순화 — 사장 신뢰 모델)

## 14. V2 이후 로드맵

- 매장명 영문/현지어 2필드 (다국어 강화)
- 안면인식 옵션 (QR 보완)
- 자동 도어락 연동 (Bluetooth / ESP32)
- GCash 자동결제 (구독료)
- 리뷰·평점
- Sentry · 분석 도구
- 알림 종류별 채널 차등
- 트레이너 다중 매장 통합 화면
- 구글 OAuth (V1.5)

> **알림 채널 확정**: 푸시(Web Push) + 이메일(transactional) 2채널만 운영. SMS·문자, 그리고 사장 → 회원 단체 발송(broadcast)은 비용 사유로 도입하지 않음.

> **마사지샵·호텔·식당·살롱 등 다른 업종은 V2가 아니라 별도 프로젝트**로 분리 운영. 본 명세를 그대로 복제 후 vertical 특화 부분만 수정.
