# 예약 시스템 (Booking)

## 예약 단위

- 30분 또는 60분 (서비스 등록 시 사장이 선택)

## 정원 (동시 예약 수)

- 서비스별 사장 설정 (기본 1명)
- PT 등 1:1 서비스: 보통 1명
- 단체 수업: 5/10/20명 등 자유 설정
- 정원 차면 자동 차단 (해당 시간 슬롯 비활성화)

## 빈 시간 슬롯 자동 계산

### 입력값
- 매장 영업·휴게시간
- 직원 근무·휴무
- 기존 예약
- 서비스 시술 진행 시간
- 시간 단위 (30/60분)
- 서비스 정원

### 출력
- 예약 가능 슬롯만 표시
- 불가 슬롯은 비활성화 또는 숨김
- 단체 수업 정원 초과 시 자동 차단

## 예약 흐름

> 고객은 본인 가맹점(`/g/{slug}/...`) 안에서만 예약. 다른 가맹점 예약은 별도 계정 + 별도 가맹점 URL.

1. 서비스 선택 (PT, 요가, 필라테스 등)
2. 날짜 선택
3. 트레이너 선택:
   - 특정 트레이너 (예: 김트레이너)
   - "아무나" — 전 트레이너 통합 빈 시간
   - 미선택 시 자동으로 "아무나"
4. 빈 시간 슬롯 표시 (선택에 따라 필터링)
5. 시간 선택 후 예약 신청

### 직원 선택 예외
- **단체 수업**: 트레이너 고정 → 직원 선택 X
- **자유 운동**: 예약 자체 X (QR 출입만)

## 자유 운동

- 예약 row 생성하지 않음
- QR 출입 로그만 기록 (`access_log`)
- 매장 자체 정원 개념 없음 (현장 인원 무제한)
- 사장 매출·방문 통계는 access log 기반 집계 (PT·단체와 구분 표시)

## 단체 수업

- 정원이 정해진 N명 슬롯 (예: 요가 20명)
- 정원 차면 자동 차단
- 같은 시간에 N개 예약 row 생성 (참석자별 1 row)
- 트레이너는 고정 (서비스 등록 시 지정)

### 참석자 명단·출석
- 명단 조회 권한:
  - **사장·매니저**: 매장 모든 단체 수업 명단
  - **담당 트레이너**: 본인이 진행하는 단체 수업 명단만
  - **다른 트레이너**: 조회 불가
- 명단 표시: `김민수, 박지영, 이수진 ... 전체 16명` (긴 경우 말줄임 + 클릭 시 상세)
- **출석 토글 UI**: 사장 또는 담당 트레이너가 회원별 "출석 / 노쇼" 체크
  - 노쇼 체크 시 자동 신뢰도 -30
  - 출석 체크 시 자동 신뢰도 +5

## 예약 승인 분기

### 케이스 A: 예약금 없는 매장 (자동 승인)
1. 예약 신청 → 즉시 확정
2. 사장·담당 직원에게 알림 (새 예약)
3. 1시간 전 리마인더 (고객·직원)
4. 방문·시술
5. 사장 또는 담당 직원이 "완료" 수동 처리
6. 신뢰도 +5

### 케이스 B: 예약금 있는 매장 (수동 승인)
1. 예약 신청 → GCash QR + 입금 안내 표시
2. 고객이 매장 GCash로 직접 입금 (오프라인)
3. 사장·직원에게 알림 (입금 확인 요청)
4. 사장이 본인 GCash에서 입금 확인 (오프라인)
5. 시스템에서 "입금 확인 완료" 수동 승인
6. 예약 확정 → 고객에게 알림
7. 1시간 전 리마인더 → 방문·시술 → 완료 처리 → 신뢰도 +5

### 예약금 정책
- 우리 플랫폼은 예약금에 관여 X
- 매장이 직접 환불 처리
- 시스템은 "입금 확인 여부"만 기록

## 예약 변경

### 고객 직접 변경
- **하루 전까지만** 가능
- 시간 변경 시 빈 슬롯 재선택
- 예약금 있어도 시간만 변경 (재입금 X)
- 패널티 X

### 직원·사장이 변경 (당일 가능)
- 고객이 당일 급한 일로 전화 → 직원·사장이 시스템에서 변경
- **신뢰도 패널티 X** (정상 변경)
- 노쇼와 명확히 다른 액션
  - 데이터 모델: `reservation_log` 테이블에 액션 타입 분리 (`changed_by_staff` vs `no_show`)
  - UI: 별도 버튼 (변경 / 노쇼)

## 예약 취소·거절

- 고객 직접 취소 가능 (예약금 환불은 매장과 직접 협의)
- 사장 거절 가능 (사유 입력 옵션, 예약금 환불 안내)
- 단체 수업 취소 시 정원 자동 복구 (다른 사람 예약 가능해짐)

## 사장·트레이너가 직접 예약 등록

- 단골이 전화로 부탁 시 사장·트레이너가 회원 대신 예약
- **회원만 가능** (비회원 예약 X)
- 비회원이 매장 방문 시 태블릿에서 신규 회원 등록 → magic link 메일 → PWA 설치 (자세한 흐름 → [auth.md](./auth.md))

## 트레이너 긴급 변경

1. 트레이너·사장이 시스템에서 예약 변경·취소
2. 고객 전화번호 자동 표시 (담당 트레이너에게)
3. 트레이너가 직접 전화로 양해 구함
4. 새 시간 협의 후 시스템 반영
5. 패널티 X (직원 변경 액션)

> 가맹점 간 예약 시간 중복 검사는 안 함. 고객 계정이 가맹점별 분리이므로 시스템이 다른 가맹점 예약 정보에 접근 불가.

## 자동 처리 안 함

- 자동 완료 처리 X
- 모든 완료·노쇼·취소는 사장·직원 수동 처리
