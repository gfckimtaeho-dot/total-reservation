# 매장 관리 (Business)

> 모든 도메인 row는 `gym_id`(=Business의 PK) 스코프. 매장 간 횡단 접근 없음.
> 매장 등록 흐름 자체는 [auth.md](./auth.md)의 "사장 (매장 등록)" 참조. 본 문서는 폼 필드·운영 데이터·권한 모델만 다룸.

## 매장 등록 — 필수 입력 (invite 폼)

- 매장명
- 슬러그 (영문/숫자/하이픈, 시스템 예약어 금지, **실시간 중복 체크 — 다른 매장과 충돌 시 즉시 안내**)
- 시 + 동 (PSGC)
- 매장 대표 전화
- 사장 이름·이메일·비밀번호·전화번호

> **슬러그 = `yeyak.com/g/<여기>` 의 `<여기>`**. 매장 외부 홈페이지와 무관. 우리 플랫폼 안에서 그 매장의 고유 주소이자 매장 공개 페이지(=매장 홈페이지 역할) URL.

## 공개 매장 페이지 (`yeyak.com/g/{slug}/`)

매장 자체 홈페이지를 대체하는 공개 페이지. **비회원도 진입 가능**. 매장이 자기 페이지 URL을 인스타·페북·전단지에 공유 → 잠재 손님이 미리 둘러보고 → 매장 방문 결정 → 트레이너가 태블릿에서 가입. 즉 *진입 trigger* 역할.

### 표시 항목 (사장이 대시보드에서 채운 항목만 자동 노출, 빈 항목은 숨김)

- 매장명·로고·hero 사진
- 매장 사진 갤러리 (최대 10장)
- 매장 소개 텍스트
- 위치 (시·동·상세 주소)
- 영업시간·휴게시간
- 서비스 리스트 (서비스명·정원·시간 단위·시술 시간·가격)
- 트레이너 카드 (사진·이름·소개·경력)
- 멤버십·PT 패키지 가격표
- 매장 대표 전화·연락 안내
- "회원이 되시려면 매장에 방문해 주세요" CTA + 약도/연락처

### 정책

- **공개 가입 폼 X** — 가입은 여전히 매장 방문 100% (트레이너가 태블릿에서 등록). 페이지에는 가입 신청 form 두지 않음
- 회원이 페이지에 접속하면 PWA 설치 가이드 + `/g/{slug}/login` 또는 `/g/{slug}/me` 진입 링크 노출
- 차단(`Business.status = blocked`) 또는 만료 가맹점은 페이지 비활성화 (관리자 안내만)
- 검색 모듈은 V1엔 X (가맹점 모델). 매장이 자기 URL을 직접 공유하는 흐름

## 등록 후 대시보드에서 점진적으로 채움

- 매장 사진 (최대 10장)
- 매장 전화번호·상세 주소
- 영업시간 (요일별)
- 휴게시간 (옵션)
- 예약금 여부 + GCash QR 코드 사진
- 서비스·트레이너·멤버십·PT 패키지

> "필수 폼 필드"는 위 5개로 최소화. 나머지는 화면 구상 진행하면서 점진적으로 추가.

## 매장 사진

- Cloudinary 자동 압축
- 단일 파일 10MB 이하
- 허용 형식: JPG / PNG / WebP / HEIC (HEIC는 iPhone 기본)
- 동영상 미지원
- 최대 10장

## 영업시간 처리

- 24시간 영업: `00:00 ~ 23:59`
- 단축 변경 시 기존 승인 예약과 충돌 검사
  - 충돌 있으면 변경 불가
  - 사장이 먼저 고객에게 전화로 양해 → 예약 시간 변경 → 영업시간 변경

## 예약금 여부

- "예약금 받지 않음" — 자동 승인 흐름
- "예약금 받음" — GCash QR 코드 사진 등록 필수, 수동 승인 흐름

## 트레이너 등록 (사장이 직접)

- 권한 레벨: `trainer` 또는 `manager`
- 이름·사진(얼굴)·소개·경력
- 이메일·전화번호 (긴급 연락용)
- 시스템이 magic link 메일 발송 → 트레이너가 클릭 → 비번 설정 후 활성화 (자세한 흐름 → [auth.md](./auth.md))
- 추가·수정·삭제 가능
- "초대 재발송" 버튼으로 magic link 재발송 가능

## 서비스 등록

- 서비스명 자유 입력 (예: PT, 필라테스, 요가, 단체 수업)
- 정원 (최소 1명, 단체는 자유 설정 — 5/10/20명 등)
- 가격
- 시간 단위 (30분 또는 60분)
- 시술 진행 시간 (예: PT 60분, 요가 90분)
- 추가·수정·삭제 가능

## 멤버십 (헬스장 출입권)

- 사장이 자유 설정 (예: 1개월 1500₱, 6개월 8000₱, 1년 14000₱)
- 회원에게 판매 시 사장·매니저·트레이너가 회원 편집 화면에서 등록 (시작일·종료일·금액)
- **결제는 매장 직접 (시스템은 기록만)**
- 만료일 도달 시 QR 자동 발급 차단
- 만료 7일 전 알림 (옵션)

## PT 패키지 (회당 시술권)

- 사장·매니저·트레이너가 회원 편집 화면에서 등록 (예: PT 10회권, PT 1회당 60분)
- **예약 확정 시 자동 차감** (잔여 횟수 카운터 -1)
- 잔여 0회 시 새 패키지 결제 안내

> 멤버십 ≠ 서비스 — 분리 관리. 회원은 멤버십(출입권)으로 헬스장 입장 + 별도로 PT/요가/단체 수업 예약·결제.

## 권한 모델

### 사장 (Owner)
- 모든 권한
- 매장 삭제 가능 (유일)

### 매니저 (Manager)
- 사장과 동등 권한
- 매장 삭제만 불가
- 사장이 직원 편집 화면에서 트레이너 → 매니저 승격·강등 가능

### 트레이너 (Staff)
- 본인 예약 등록·조회·관리·완료 처리
- 본인 휴무·휴게 등록
- 본인 예약 고객 전화번호 조회
- **회원 등록 + 멤버십·패키지 결제 가능** (사장 부재 시 신규 손님 등록 대응)
- 다른 직원 예약·고객 정보는 조회 불가

## 트레이너 다중 매장

- 한 사람이 가맹점 A·B 트레이너 → **각 가맹점에 별도 계정** (`(email, gym_id)` unique 덕에 같은 이메일 사용 가능)
- 가맹점별로 따로 로그인 (통합 화면 V2)

## 임시 휴무

- 사전 등록만 가능 (승인 예약 있으면 등록 불가)
- 당일 결근은 "긴급 변경" 워크플로우 사용 (예약 페이지에서 직접 변경 + 고객 전화)
- 사장이 연초 또는 가입 시 미리 등록 권장
