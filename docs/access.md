# 출입 시스템 (Access)

## 적용 범위

- 모든 가맹점 회원에게 QR 발급 (멤버십 활성 시)
- 자유 운동·PT·단체 수업 모두 동일 QR로 입장

## QR 코드 사양

- **5분 유효, 일회용** (1회 사용 후 무효)
- 암호화된 서명 포함 (위조 방지, JWT 또는 HMAC)
- 페이로드: `business_id` + `member_id` + `issued_at` + `nonce` + 서명

## QR 화면 표시 정보

- 회원 이름 (예: "김민수")
- 매장 이름 (예: "ABC 헬스장 회원")
- 멤버십 만료일 (예: "2026-12-31 까지")
- QR 이미지
- 만료 카운트다운 (예: "00:04:23 후 만료")
- "재발급" 버튼

## 출입 검증 흐름

1. 회원이 앱에서 QR 생성 요청
2. 서버가 멤버십 유효성 확인 (만료일 체크)
3. QR 발급 (5분 유효)
4. 매장 스캐너에 스캔
5. 서버 검증 (서명·만료·중복 사용 체크)
6. OK 또는 거절 응답
7. 도어락 열림 (V2 자동화, V1은 수동 안내)
8. 출입 로그 저장 (`access_log`)

## 자유 운동 통계

- 자유 운동은 예약 row 없음
- QR 출입 로그가 유일한 방문 기록
- 사장 매출·방문 통계 화면에서 PT·단체·자유 운동 구분 표시
- 일별·주별·월별 자유 운동 방문자 수 집계

## 멤버십 만료 처리

- 만료일 다음날부터 QR 자동 발급 차단
- 만료된 회원이 출입 시도 → 스캐너에서 "만료" 표시
- 만료 7일 전 알림 (옵션, 사장이 매장별로 설정)

## 매장 측 장비 (V1)

- 태블릿 + QR 스캐너 앱 (저렴한 옵션)
- 매장 스캐너는 항상 온라인 가정
- **PWA 오프라인 시 출입 검증 안 함, 그냥 입장 허용** (V1 단순화 — 사장 신뢰 모델)

## V2 로드맵

- 자동 도어락 연동 (Bluetooth 또는 ESP32 등)
- 안면인식 옵션 (QR 보완)
- 매장 스캐너 오프라인 캐시 (네트워크 끊겨도 검증 가능)
